# study_planner_app

A Study Planner mobile app built with **Flutter**.  
Features: task creation (title, description, due date, optional reminder), "Today" list, calendar view with highlighted dates, simulated reminders (popups on app open), animated progress indicator, and local persistence using **SharedPreferences** storing tasks as JSON.

---

## Demo / Goal

This app was created as part of a mobile dev assignment to practice:
- Multi-screen navigation and `BottomNavigationBar`.
- Local persistence using JSON (SharedPreferences).
- Widgets & forms, date/time pickers.
- Simple simulated reminders and UI animations.
